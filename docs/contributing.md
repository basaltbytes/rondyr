# Contributing

Rondyr is open source under the [GNU Affero General Public License v3.0](../LICENSE) (and the EmDash plugin under [MIT](../packages/emdash-plugin/LICENSE)). Documentation for running Rondyr locally, changing the codebase, evaluating spam classifiers, and operating the infrastructure stays in the GitHub repository:

- [Contributing guide](../CONTRIBUTING.md): branch rules, workspace checks, browser tests, and pull requests.
- [Local development](./local-development.md): run Rondyr on your machine with no Cloudflare account.
- [Write a connector](./writing-a-connector.md): send accepted messages to another service with one file.
- [Classifier evaluation](./evaluation.md): replay labeled corpora to measure Jev and OpenAI Decisions thresholds.
- [Operations runbook](./operations.md): backlog diagnostics, smoke tests, database restores, and rollbacks.
- [Coding and writing rules](../AGENTS.md): conventions for human contributors and coding agents.

Check the [open issues](https://github.com/basaltbytes/rondyr/issues) to see the roadmap. To report a security vulnerability privately instead of opening an issue, follow [SECURITY.md](../SECURITY.md).
